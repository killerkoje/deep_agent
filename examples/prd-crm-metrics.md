# CRM 지표 대시보드 — PRD

## 왜 만드는가

영업팀이 매달 지표를 수기로 취합하고 있다. 엑셀을 서로 주고받다 보니
같은 달 숫자가 사람마다 다르게 나오는 일이 반복된다.

## 범위

### 1. 신규 고객 수

월별 신규 고객 수를 카드로 보여준다. 전월 대비 증감도 같이 본다.

### 2. 지점별 매출

지점별 매출을 표로 보여주고, **매출 상위 10개 지점 랭킹**을 노출한다.

### 3. 조회 권한

- 본사 담당자는 전 지점을 본다
- **지점 관리자는 자기 지점만 조회한다**

### 4. 취소 반영

취소된 주문은 매출에서 차감한다.

## 이미 정해진 것

- 기존 CRM 백엔드(FastAPI)에 API를 추가한다. 새 서비스는 만들지 않는다
- 화면은 기존 관리자 페이지 안에 탭으로 넣는다

## 아직 안 정한 것

- 데이터 새로고침 주기
